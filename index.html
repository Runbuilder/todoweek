URL·RSS·YouTube·SNS 주소 또는 학습할 문서를 추가할 수 있습니다. PDF·TXT·MD·CSV·JSON·DOCX·PPTX·HWPX를 지원합니다. URL만 있으면 현재 메뉴의 주간 브리핑을 만들고, 문서가 하나라도 첨부되면 자동으로 학습 TODO 모드로 전환하여 문서 내용을 한 주에 나눠 학습 카드로 배치합니다.
Instagram·Threads 프로필은 직접 접근이 불안정합니다. RSS.app의 공개 피드 URL을 등록하면 앱 서버가 RSS XML을 직접 읽고 ITEM 단위로 분석한 뒤 Google Search로 교차검증합니다.
📚 문서가 첨부되어 학습 TODO 모드로 전환되었습니다. 이번 주 카드는 뉴스가 아니라 문서의 학습 순서와 핵심 내용을 기준으로 생성됩니다.
URL만 입력하면 주간 브리핑, 문서를 첨부하면 학습 TODO 모드로 동작합니다. 문서 학습 모드에서는 첨부한 자료의 실제 내용과 구조를 기준으로 학습 분량을 나눕니다.

    Google 로그인 필요
    🔐 내 Gemini API Key
    사용자별로 암호화해 Supabase에 저장합니다.
    확인 중
    API Key 원문은 브라우저 localStorage와 일반 DB 컬럼에 저장하지 않습니다. Edge Function에서 검증한 뒤 서버 측에서 암호화하여 보관합니다.
    ① 빠른 주간 브리핑 모델
    AI 채우기에서 Google Search + URL Context로 빠르게 조사하고 카드를 구성합니다.
    ② 선택 카드 심층 분석 에이전트
    카드 상세 화면에서 사용자가 심층 분석을 누를 때만 실행합니다.
    ③ 유튜브 콘텐츠 작성 모델
    카드와 원본 문서·출처를 바탕으로 런빌드 규칙의 한국어 스크립트를 작성합니다.
    ☁ 내 클라우드 데이터
    Google 로그인 사용자 ID를 기준으로 메뉴, 카드, 문서, 스크립트를 분리합니다. 다른 사용자의 데이터는 RLS 정책으로 접근할 수 없습니다.
    로그인 상태를 확인하고 있습니다.
    이 브라우저에서 V6 이전 로컬 자료를 발견했습니다. 현재 Google 계정의 클라우드 공간으로 한 번 가져올 수 있습니다.
